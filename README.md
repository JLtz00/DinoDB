> Proyecto académico enfocado en la construcción de un motor de base de datos desde cero.

---

## 📌 Descripción

Este proyecto tiene como objetivo desarrollar un **Mini Sistema Gestor de Bases de Datos (SGBD)** en **C++17**, con fines educativos.

La intención es comprender cómo funcionan internamente los sistemas gestores de bases de datos, implementando sus componentes principales desde un nivel bajo, en lugar de utilizar soluciones ya existentes.

---

## 🧠 Idea del Proyecto

Se busca responder a la siguiente pregunta:

> ¿Cómo un sistema puede almacenar, organizar y recuperar datos de manera eficiente?

Para ello, el proyecto se centrará en construir un motor capaz de:

- Almacenar datos de forma persistente en disco  
- Gestionar memoria de manera eficiente  
- Permitir búsquedas rápidas mediante estructuras de índice  
- Ejecutar consultas básicas sobre los datos  

---

## 🏗️ Enfoque de Implementación

El desarrollo del sistema se realizará de manera modular, dividiéndolo en componentes principales:
- Storage Manager -> Manejo de datos en el disco
- Buffer Manager -> Gestión de demoria
- Indez -> Estructuras de búsquedas (B+ Tree)
- Query Processor -> Ejecución de consultas

Cada módulo será implementado progresivamente a lo largo del proyecto.
